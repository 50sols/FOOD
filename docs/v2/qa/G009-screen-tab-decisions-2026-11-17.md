# G009 — per-screen four-way horizontal-tab decisions (source-linked)

**Atomic owner:** [Issue #3991](https://github.com/walidatiyaai2025-gif/FOOD/issues/3991); **scope:** documentation-only reconciliation; **exact integration source:** [Foodex_V2@`5c5c76cf252ba184dc9eb544397f929e291999af`](https://github.com/walidatiyaai2025-gif/FOOD/commit/5c5c76cf252ba184dc9eb544397f929e291999af). Parent UX gate [#2750](https://github.com/walidatiyaai2025-gif/FOOD/issues/2750), master [#2503](https://github.com/walidatiyaai2025-gif/FOOD/issues/2503) remain OPEN.

## Scope and decision rule

- **500 source records:** 200 GET-like server route records, 187 Blade files including dialogs/details/partials, 113 Flutter route/class/screen records (Customer 85, Driver 6, Van 22). These are NOT distinct rendered screens. One route may reuse a Blade view, and a Dart file may define several screen classes.
- Of 200 route records, **66 are NOT_A_SCREEN** — downloads, API, feeds, callbacks and a directly verified Supply entry redirect. These are listed for exhaustive traceability **outside** the four *screen* choices. Remaining **134 potential HTML screen-route records** + 187 Blade source files + 113 Flutter screen/class records = **434 screen/source records** receiving exactly one of the four decisions. A Blade partial is a source record, not an independently navigable route; the parent controls its navigation.
- **CONVERT_TO_HORIZONTAL_TABS:** independent substantial sibling workspaces repeatedly revisited under one authorized page. This is a proposed *source decision*, not a merged conversion or automatic permission to edit an owned file.
- **KEEP_EXISTING_TABS:** existing authorized page-level horizontal tab rail or native Flutter TabBar; preserve rather than replace or duplicate. Compliance requires actual RTL/keyboard/viewport testing later; source-only recognition is not a runtime certification.
- **NO_TABS_SINGLE_FLOW:** one coherent form, list, record detail, dashboard/report or a parent-owned embedded fragment; number of visual cards/HTML sections alone does not imply tabs.
- **SKIP_SECURITY/LOGIN/WIZARD:** login, installation/setup, MFA, privileged RBAC/security editing, checkout, approvals, delivery evidence or ordered dependent workflows; adding navigation would invite bypass/loss of state.
- **Authority:** route guards, effective RBAC, active-role DENY, tenant/store/channel entitlements, CSRF, maker/checker and business transitions remain server-authoritative. Hidden panels never grant permissions and should not contain unauthorized sensitive data. No change to B2B VAN ONLY / B2C DRIVER ONLY.
- **Confidence:** STATIC_SOURCE_ONLY. Source links point to current `Foodex_V2` files; route-to-view binding candidates, role-dependent runtime HTML, generated dynamic sections, device/browser rendering and keyboard focus remain unverified. Tests in the prior inventory are references only, **not tests newly run in this documentation task**.

- Original route classification [#2750 checkpoint](https://github.com/walidatiyaai2025-gif/FOOD/issues/2750#issuecomment-6938015069) provided 200 route records, 65 not-screens. The site-specific `/sites/{site}/supply` remains a tab candidate owned by #3954/PR #3988.
- Old `/admin/erp` route and `admin/erp-center.blade.php` were classified single flow. Direct current Blade inspection shows four independent Snapshot/Analytics/My Work/Modules regions without a page rail; they are now **CONVERT candidates** under existing original #3960/PR #3961. This docs PR makes no code edit.
- Old `/admin/whatsapp/campaigns/{campaign}/report` route was a broad candidate merely because parent campaign workspace has tabs. Direct current report Blade shows a coherent *single campaign report* (KPI, funnel, suppression, opt-out, delivery and recipient breakdowns), so the detail route remains **NO_TABS_SINGLE_FLOW**. Parent Campaign workspace is still #3955/PR #3980-owned.
- Old Growth route classified CONVERT even after #3952/PR #3957 merged six server-chosen horizontal page tabs; current source proves **KEEP_EXISTING_TABS**. No second conversion.
- Shared `.foodex-tabs/.foodex-tab` primitive and Action Center six-tab pattern are references, not mandatory copies of arbitrary HTML. Local GET navigation and full ARIA Tab widgets have different keyboard obligations. See [G009 pattern discussion](https://github.com/walidatiyaai2025-gif/FOOD/issues/2750#issuecomment-6938985173).
